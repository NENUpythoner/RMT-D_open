## Overview

**RMT-D** is a random matrix theory (RMT)-based denoising method designed for **resting-state functional magnetic resonance imaging (rs-fMRI)**.

The method performs adaptive local low-rank modeling of BOLD time series and aims to suppress unstructured random thermal noise while preserving spatially localized BOLD dynamics and their temporal correlation structure.
